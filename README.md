# Pad Diff Tool

用于对比PCB焊盘的小工具(假如设计的板子需要量产，那么对于代工厂来说，版本的更新对于线路或者焊盘的变动会导致治具不匹配，此工具可以快速对比变动位置)，手边没有趁手的对比工具于是做了个，逻辑较简单，识别率较差，不适配手机端，不支持多层板

典型用法：在AD中隐藏其它层，只显示 Top Overlay、Top Solder、Bottom Overlay、Bottom Solder、Multilayer，然后直接全选复制到Windows画图直接导出为PNG格式文件，导入[此工具](https://sekibetu.com/PadDiffTool/)即可

因为只考虑了我自己的用法，所以其他种类的图片需要自行探索

功能都在界面上写着
